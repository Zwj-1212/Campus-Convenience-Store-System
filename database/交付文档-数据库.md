## 三、关键设计说明（后端必读）

### 3.1 批次级库存（inventory 表）

同一商品的多次进货在 `inventory` 中各占一行，通过 `detailId` → `purchasedetail` 追溯来源批次：

```text
商品"乐事薯片"有 2 个批次:
  inventoryId=1:  detailId=1, quantity=89,  expiryDate=2026-09-15 (4月1日进货)
  inventoryId=21: detailId=21, quantity=60, expiryDate=2026-10-10 (4月20日补货)
```

查询商品**总库存**：`SELECT SUM(quantity) FROM inventory WHERE productId=1`

### 3.2 FIFO 批次扣减（POS 销售核心）

销售时按 **expiryDate ASC** 排列，从最早过期的批次开始扣减：

```sql
-- 步骤1：加锁查询该商品所有有库存的批次（防超卖）
SELECT inventoryId, quantity, expiryDate
FROM inventory
WHERE productId = ? AND quantity > 0
ORDER BY expiryDate ASC
FOR UPDATE;   -- 行级锁

-- 步骤2：逐批扣减（Java代码循环执行）
-- 例如：需扣减 5 件，批次A(3件)+批次B(50件)
--   → UPDATE inventory SET quantity=0 WHERE inventoryId=A
--   → UPDATE inventory SET quantity=45 WHERE inventoryId=B

-- 步骤3：扣减后检查是否触发缺货预警
SELECT SUM(quantity) FROM inventory WHERE productId = ?;
-- 若 SUM < product.alertMin → INSERT stockalert(alertType=1)
```

### 3.3 进货两阶段提交

```text
阶段1（草稿）: INSERT purchase(status=0) + INSERT purchasedetail(多条)
阶段2（确认）: UPDATE purchase SET status=1
               → 逐条 INSERT inventory(detailId, expiryDate)
               → 更新 product.defaultPrice
全程在一个事务内完成。
```

### 3.4 totalAmount 自洽

进货单和销售单的 `totalAmount` 必须由 **Service 层自动计算**，不允许前端传值：

- 进货：`totalAmount = SUM(purchasedetail.purchasePrice × quantity)`
- 销售：`totalAmount = SUM(saledetail.unitPrice × quantity)`

## 四、后端 DAO 层 SQL 速查

### 4.1 登录

```sql
SELECT userId, username, realName, role, phone
FROM user
WHERE username = ? AND password = ?;  -- password 是 SHA-256 哈希
```

### 4.2 商品搜索（关键字 + 条码）

```sql
SELECT p.*, c.categoryName,
       COALESCE(SUM(i.quantity), 0) AS totalStock
FROM product p
LEFT JOIN category c ON p.categoryId = c.categoryId
LEFT JOIN inventory i ON p.productId = i.productId
WHERE (p.productName LIKE CONCAT('%',?,'%') OR p.barcode = ?)
  AND p.status = 1
GROUP BY p.productId;
```

### 4.3 POS 扫码快速查找

```sql
SELECT p.*, COALESCE(SUM(i.quantity), 0) AS totalStock
FROM product p
LEFT JOIN inventory i ON p.productId = i.productId
WHERE p.barcode = ? AND p.status = 1
GROUP BY p.productId;
```

### 4.4 库存充足性校验

```sql
SELECT productId, SUM(quantity) AS totalStock
FROM inventory
WHERE productId IN (?, ?, ?)
GROUP BY productId;
```

### 4.5 进货单列表

```sql
SELECT pu.purchaseId, s.supplierName, u.realName AS operator,
       pu.purchaseDate, pu.totalAmount, pu.status
FROM purchase pu
JOIN supplier s ON pu.supplierId = s.supplierId
JOIN user u ON pu.userId = u.userId
ORDER BY pu.purchaseDate DESC;
```

### 4.6 销售记录

```sql
SELECT s.saleId, u.realName AS cashier, s.saleTime,
       s.totalAmount, s.paymentMethod
FROM sale s
JOIN user u ON s.userId = u.userId
ORDER BY s.saleTime DESC
LIMIT ?, ?;  -- 分页
```

### 4.7 按商品汇总库存

```sql
SELECT p.productId, p.productName, c.categoryName,
       p.alertMin, p.defaultPrice,
       COALESCE(SUM(i.quantity), 0) AS totalStock,
       CASE WHEN COALESCE(SUM(i.quantity), 0) < p.alertMin
            THEN 1 ELSE 0 END AS isLowStock
FROM product p
LEFT JOIN category c ON p.categoryId = c.categoryId
LEFT JOIN inventory i ON p.productId = i.productId
WHERE p.status = 1
GROUP BY p.productId
ORDER BY totalStock ASC;
```

### 4.8 批次明细（含距过期天数）

```sql
SELECT i.inventoryId, i.productId, p.productName,
       i.quantity, i.expiryDate,
       DATEDIFF(i.expiryDate, CURDATE()) AS daysToExpire,
       pd.purchasePrice, pu.purchaseDate
FROM inventory i
JOIN product p ON i.productId = p.productId
LEFT JOIN purchasedetail pd ON i.detailId = pd.detailId
LEFT JOIN purchase pu ON pd.purchaseId = pu.purchaseId
WHERE i.productId = ?
ORDER BY i.expiryDate ASC;
```

### 4.9 首页仪表盘

```sql
-- 今日销售概览
SELECT COUNT(*) AS todayOrders,
       COALESCE(SUM(totalAmount), 0) AS todaySales,
       ROUND(COALESCE(AVG(totalAmount), 0), 2) AS avgOrderValue
FROM sale WHERE DATE(saleTime) = CURDATE();

-- 近7日趋势
SELECT DATE(saleTime) AS saleDate, COUNT(*) AS orders, SUM(totalAmount) AS sales
FROM sale WHERE saleTime >= DATE_SUB(CURDATE(), INTERVAL 7 DAY)
GROUP BY DATE(saleTime) ORDER BY saleDate;

-- 未处理预警数
SELECT COUNT(*) FROM stockalert WHERE status = 0;
```

### 4.10 统计查询

```sql
-- 供应商月度送货统计
SELECT DATE_FORMAT(pu.purchaseDate, '%Y-%m') AS month,
       s.supplierName,
       SUM(pd.quantity) AS totalQuantity,
       SUM(pd.purchasePrice * pd.quantity) AS totalAmount
FROM purchase pu
JOIN supplier s ON pu.supplierId = s.supplierId
JOIN purchasedetail pd ON pu.purchaseId = pd.purchaseId
WHERE pu.status = 1
GROUP BY month, pu.supplierId;

-- 类别月度销售统计
SELECT DATE_FORMAT(s.saleTime, '%Y-%m') AS month,
       c.categoryName,
       SUM(sd.quantity) AS totalQuantity,
       SUM(sd.subtotal) AS totalSales
FROM sale s
JOIN saledetail sd ON s.saleId = sd.saleId
JOIN product p ON sd.productId = p.productId
JOIN category c ON p.categoryId = c.categoryId
GROUP BY month, c.categoryId;

-- 单品销量排行 TOP 10
SELECT p.productName, c.categoryName,
       SUM(sd.quantity) AS totalQuantity,
       SUM(sd.subtotal) AS totalSales
FROM saledetail sd
JOIN product p ON sd.productId = p.productId
JOIN category c ON p.categoryId = c.categoryId
GROUP BY sd.productId
ORDER BY totalQuantity DESC LIMIT 10;
```
